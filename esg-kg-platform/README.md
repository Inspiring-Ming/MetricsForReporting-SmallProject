# Run Services

## To run frontend, backend, and graphDB services, please follow instructions below:

1. `cd MetricsForReporting-SmallProject/esg-kg-platform`
2. `make help`
3. `make up`

## Now you have three services runing:

- **Frontend:** [http://localhost:3001](http://localhost:3001)  
- **Backend API:** [http://localhost:3000](http://localhost:3000)  
- **GraphDB:** [http://localhost:7200](http://localhost:7200)

## Notes

1. Make sure you have docker downloaded on your device. You can find latest desktop version here: <https://www.docker.com/products/docker-desktop/>
2. First time startup may take 3-5 mins.
